# AgendaPro

Business Appointment & Operations Management Platform.

## Overview

AgendaPro is a multi-tenant appointment scheduling and
business management platform designed for service-based
businesses.

## Technology Stack

### Backend
- PHP 8.4
- Laravel 13
- PostgreSQL 18
- Laravel Sanctum

### Frontend
- Vue 3
- TypeScript
- Vite
- Pinia
- Vue Router
- Tailwind CSS

## Architecture

The application follows a modular monolith architecture
with a separate Vue frontend and Laravel REST API.

## Project Structure

- backend/: Laravel application
- frontend/: Vue application
- docs/: Technical documentation
- .github/: GitHub workflows
